# Tollkit SMS — Mandate Flow

Buildathon submission for Arbitrum Open House London 2026.

Building AP2 mandate flow + Arbitrum settlement on top of [tollkit.dev](https://tollkit.dev)'s production x402 SMS gateway ([sms.tollkit.dev](https://sms.tollkit.dev)).

Deliverables:
- `ConsentMandateRegistry.sol` on Arbitrum Sepolia
- AP2 Intent Mandate flow in the seller
- Batch settlement every 5 SMS via x402 V2
- Multi-chain (Base + Arbitrum) support
